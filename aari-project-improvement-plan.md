## 🛠️ 2. Detailed Improvement Roadmap (Phase-by-Phase)

### 🔴 Phase 1: High-Priority Fixes (Security & Performance)

#### 1.1 Fix Monster Asset Sizes (Favicon & Icons)
- **Problem:** `public/favicon.ico` and `public/icon.png` are **902,883 bytes (~900 KB)** each! Every single visitor downloads 1MB just for the browser icon.
- **Fix:**
  - Generate a crisp, optimized 32x32 / 48x48 `.ico` and 192x192 / 512x512 `.png` under 15 KB.
  - Implement Next.js App Router metadata icon helpers.

#### 1.2 Rate Limiting & Honeypot on Enquiry API (`vulnerability-scanner`)
- **Problem:** `POST /api/enquiry` is completely unprotected. Anyone or any automated scraper can send thousands of requests and fill up PostgreSQL.
- **Fix:**
  - Add in-memory or LRU/Upstash rate limiting (e.g. 5 requests per IP per 10 minutes).
  - Add a hidden Honeypot field (`website_url_check`) in `EnquiryForm.tsx` to trap spam bots silently.
  - Sanitize string inputs before database insertion.

#### 1.3 Add HTTP Security Headers in `next.config.ts`
- **Fix:** Add security headers to `next.config.ts`:
  - `Content-Security-Policy`
  - `X-Frame-Options: SAMEORIGIN`
  - `X-Content-Type-Options: nosniff`
  - `Referrer-Policy: strict-origin-when-cross-origin`
  - `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload`

#### 1.4 Clean Root Directory Clutter
- **Fix:**
  - Remove or relocate `SKILL (1).md` (canvas-design), `SKILL (2).md` (brand-guidelines), `SKILL.md` from the root directory.
  - Add `backup/` to `.gitignore`.
  - Add AG Kit helper scripts to root `package.json` (`npm run check:agents`, `npm run verify`).

### 🟡 Phase 2: SEO, GEO & Search Engine Domination

#### 2.1 Dynamic `sitemap.ts` and `robots.ts` (`seo-fundamentals`)
- **Problem:** Search engines (Google, Bing) and AI crawlers (Perplexity, ChatGPT Search) cannot find clean index directives.
- **Fix:**
  - Create `src/app/sitemap.ts` returning canonical URLs, images, and lastModified timestamps.
  - Create `src/app/robots.ts` allowing indexing of public pages and disallowing `/api/` and future `/admin/`.

#### 2.2 Next.js Error Boundaries & Status Pages
- **Fix:**
  - Add `src/app/not-found.tsx` with branded luxury Aari aesthetic ("Page not found - return to our bridal gallery").
  - Add `src/app/error.tsx` (Client component) to handle unexpected client render crashes gracefully.
  - Add `src/app/loading.tsx` with a refined thread/needle shimmer skeleton.

#### 2.3 Rich Schema Markup (LocalBusiness, Service, Review)
- **Problem:** Currently only basic `LocalBusiness` JSON-LD exists in `layout.tsx`.
- **Fix:**
  - Add Geo coordinates (`latitude: 11.4534`, `longitude: 77.4358` for Gobichettipalayam).
  - Add `hasOfferCatalog` with individual `Service` entities (Bridal Aari Blouse, Maggam Work, Zardosi Embroidery).
  - Add `AggregateRating` for bridal testimonials.

### 🟢 Phase 3: Business Value & Conversion Enhancements

#### 3.1 Tamil / English Bilingual Toggle (`i18n-localization`)
- **Opportunity:** The studio is in Vellankovil, Gobichettipalayam, serving Erode, Tirupur, Coimbatore, and all over Tamil Nadu.
- **Fix:**
  - Add a lightweight locale toggle in the header: **EN | தமிழ்**.
  - Provide Tamil translations for Hero, Services, Process, and Enquiry form labels (e.g., *"தனித்துவமான ஆரி & மக்கம் வேலைப்பாடுகள்"*).

#### 3.2 Lead Notification System (WhatsApp / Telegram / Email)
- **Problem:** When a bride submits an enquiry, it only sits in the PostgreSQL database. If Mithanya is busy in the atelier, leads can get cold!
- **Fix:**
  - Auto-generate a pre-filled WhatsApp message link upon form submission for 1-click continuation.
  - Optional: Webhook to Telegram bot or Resend email so the owner gets pinged immediately on their phone with bride details.

#### 3.3 Protected Admin Portal (`/admin`)
- **Opportunity:** The backend already has `requireAdmin` bearer authentication and `enquiries` table status (`new`, `contacted`, `converted`).
- **Fix:**
  - Build a clean `/admin` page guarded by password/cookie or secret token.
  - View incoming enquiries with status toggles (`New`, `Called`, `Fitting Scheduled`, `Completed`).
  - Simple image upload/deletion interface for the dynamic Gallery.
